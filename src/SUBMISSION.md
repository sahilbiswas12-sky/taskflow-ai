# TaskFlow — Assignment Submission

## Project Title

TaskFlow — React Task Management Application

## Project Overview

TaskFlow is a modern, responsive task management application built with React.

The application allows users to create, manage, organize, and track their tasks through a clean dashboard interface.

The project was developed independently with AI used as a development assistant throughout the implementation process.

## Key Features

- Create tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Reopen completed tasks
- Search tasks
- Filter tasks
- Sort tasks
- View task details
- Task statistics
- Task completion progress
- LocalStorage persistence
- Light and dark mode
- Delete confirmation
- Responsive design
- Keyboard-friendly interactions
- Accessible controls
- Empty states

## Technology Stack

- React
- JavaScript
- CSS
- Vite
- Lucide React
- LocalStorage

## AI-Assisted Development

AI was used throughout development as a coding and problem-solving assistant.

It assisted with:

- Planning the application
- Breaking the project into components
- Generating initial React implementations
- Implementing state management
- Implementing LocalStorage
- Adding search and filtering
- Adding sorting
- Creating modal interactions
- Improving responsive design
- Improving accessibility
- Debugging implementation issues
- Reviewing and refactoring code

The application was developed incrementally rather than being generated as one complete project.

Each implementation stage was reviewed and tested before continuing to the next stage.

## Manual Improvements

AI-generated code was manually reviewed and modified throughout development.

Examples include:

### Duplicate Component Correction

Duplicate `App()` definitions were identified and removed so that the application contained one consistent application component.

### LocalStorage Improvements

Error handling and validation were added around LocalStorage to prevent invalid stored data from breaking the application.

### Delete Confirmation

A confirmation step was manually added to prevent accidental task deletion.

### Search and Filter Logic

Search and filtering were reviewed so that both conditions could work together correctly.

### Sorting

Sorting was implemented using copied arrays so that React state was not directly mutated.

### Accessibility

ARIA labels, keyboard focus, Escape-key support, modal roles, and mobile-friendly touch targets were added and reviewed.

### Responsive Improvements

The interface was manually reviewed at smaller screen sizes and spacing and control sizes were adjusted where required.

## Development Process

The development process followed an iterative workflow:

1. Plan the feature.
2. Write an AI prompt.
3. Review the generated solution.
4. Implement the code.
5. Run the application.
6. Test the feature.
7. Identify problems.
8. Manually correct or refactor the code.
9. Test again.
10. Continue to the next feature.
